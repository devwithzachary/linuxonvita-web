# LinuxOnVita Website

Official landing page, documentation portal, and SEO driver for the [LinuxOnVita](https://github.com/devwithzachary/LinuxOnVita) project.

## 🚀 Live Site
- Official Website: [https://linuxonvita.com](https://linuxonvita.com)
- Remote Repository: [https://github.com/devwithzachary/linuxonvita-web](https://github.com/devwithzachary/linuxonvita-web)
- Main Project Repository: [https://github.com/devwithzachary/LinuxOnVita](https://github.com/devwithzachary/LinuxOnVita)

## 🌟 Highlights
- **SEO & Social Optimization:** Full OpenGraph, Twitter Cards, canonical tags, `sitemap.xml`, `robots.txt`, and rich JSON-LD structured schemas (`SoftwareApplication`, `FAQPage`, `WebSite`).
- **Interactive Screenshot Showcase:** Switch between the 4 real native 960x544 PS Vita screenshots (`fbkeyboard`, Framebuffer DOOM, Alpine Linux with `fastfetch`, and `vita-wifi`) with full-resolution lightbox zoom.
- **Simulated Interactive Terminal:** Experience real console commands (`fastfetch`, `vita-wifi`, `alpine-chroot`, `vita-doom`, `vita-swap`) directly in the browser.
- **Hardware Matrix:** Interactive table detailing support status for CPU SMP, OLED/LCD displays, touch digitizer, gamepad buttons, analog sticks, SD2Vita, and ZRAM.
- **Step-by-Step Installation Walkthrough:** Clear guide for HENkaku / Ensō console owners, with copyable commands and troubleshooting tips.
- **Zero-Dependency Core:** Clean modern Vanilla HTML5, Vanilla CSS3, and modern client-side JavaScript.

## 🛠 Local Development

```bash
# Install development dependencies
npm install

# Start local development server with hot reload
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```

## 📦 Deployment to GitHub Pages

This site is ready for zero-configuration GitHub Pages deployment:
1. Go to repository **Settings** -> **Pages**.
2. Select **Deploy from a branch**.
3. Set Branch to `main` and folder to `/(root)`.
4. Save and your site will be live!
